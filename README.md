# RecruitAssistant Frontend Monorepo

This repository contains the frontend applications for the RecruitAssistant platform:

## Project Structure

* **[candidate-portal](./candidate-portal)**: Next.js application for candidates (runs on port 3000 by default).
* **[company-portal](./company-portal)**: Next.js application for companies/recruiters (runs on port 3001 by default).

## Running the Applications

### 1. Candidate Portal
```bash
cd candidate-portal
npm run dev
```

### 2. Company Portal
```bash
cd company-portal
npm run dev
```
